# Dashboard 性能专项优化（0.5.17，版本不变）

## 问题与改动

- 图表范围每次 render 产生新对象，导致 useMemo 失效。现在按范围选择、数据更新及北京时间跨日刷新；指标切换不再重建作品历史。
- 比较页原先为每个选中作品重新扫描完整样本集。现在共享索引一次生成时间线，切换指标只投影对应数值。
- 今日/昨日日结原先重建全部历史观察后再裁切。现在仅重建选定日内观察，仍保留更早样本供前值延续，保留零点首测和五分钟估算日界规则。
- 同一观察轮次在不同作品间反复解析日期及计算日界。现在使用有容量上限的纯时间结果缓存；不缓存可变样本、指标或日期对象。日期显示和数字格式化器按语言与格式复用。
- 作品分析和排名先按作品分组，避免逐作品过滤完整样本集。
- ECharts 初次挂载只执行一次 setOption，去掉打开图表时的入场绘制动画，保留真实采样提示、趋势处理及缩放行为。
- 屏幕外作品小图接近视口才绘制；作品卡片使用浏览器内容可见性优化。详情变化/排名记录每批显示 50 条，可继续展开；完整历史仍参与图表和计算。
- 昨日日结详情折叠后按需计算；移除增量图下反复出现的日界实现说明。

## 打包版本性能对比

同一台机器、同一 Chromium 会话、1440×1000 视口，比较修改前 ce56df7 构建包与优化构建包。均运行实际生产构建 Dashboard，通过测试专用 runtime 注入 80 件作品 × 1440 次半小时采样（115,200 条），时间固定在北京时间 2026-09-17 12:30。未访问或修改用户数据库。

每组操作重复 3 轮，以下为中位数。计时从 Playwright click 调用开始，到浏览器连续两次 requestAnimationFrame；包含自动化开销，是相对交互对比，不是 INP 或所有设备的保证。

| 操作 | 修改前 | 优化后 |
| --- | ---: | ---: |
| 进入作品 | 765 ms | 161 ms |
| 返回总览（6 次） | 2994 ms | 222 ms |
| 进入比较（未选作品） | 83 ms | 91 ms |
| 总览近 7 天 | 3291 ms | 154 ms |
| 总览近 30 天 | 4162 ms | 440 ms |
| 总览切回今日 | 3886 ms | 94 ms |
| 五作品比较：收藏 | 1571 ms | 55 ms |
| 五作品比较：获赞 | 1542 ms | 54 ms |
| 五作品比较：浏览 | 1564 ms | 54 ms |
| 五作品比较：增量 | 1565 ms | 46 ms |
| 五作品比较：总量 | 1637 ms | 54 ms |

## 验证

- TypeScript 检查通过。
- 62 个非 TSX 测试文件、461 项现有及新增计算逻辑测试通过。新增范围裁切回归覆盖旧样本延续到零点、变更指标不受缓存影响、分钟级自定义起点保留首测规则。
- 浏览器实际操作验证侧边栏、时间范围、五作品指标/总量/增量切换，以及屏幕外小图滚入视口后出现并可打开详情。
- 日结展开、详情分批显示和详情图表切换通过浏览器操作验收。
- Chrome 商店 ZIP 与本地安装目录重新构建，版本保持 0.5.17。

测试夹具、测量日志及截图在本地忽略目录 output/playwright/perf-* 和 output/playwright/performance-*；未加入产品运行路径。
