# Agent 0.5.2 验收记录

日期：2026-09-07。基于 0.5.1 的正文与对话体验优化。

## 实现范围

- 自动、正文优先、指标优先三种侧重。正文模式不自动塞入统计总览，精简统计工具及重复字段，保留数值、未知值、观测时间与来源。
- 多作品批量正文采样、元数据差异选样、正文优先预算。每问每篇累计标准最多 3,000 字 / 50%，深入最多 6,000 字 / 70%；实际还受上下文预算限制，每问最多 3 篇次。按 Unicode 字符计数，不是 tokenizer token 或网站标注字数。
- 修复并列 main 的长篇页面识别。采样只取明确正文区域的可见段落，歧义时失败；页面可能加载全文，但全文不进入 Agent 上下文或证据缓存。
- 最多 9 类 / 32 个通用问题。先识别文体，结合角色、题材、人物行动、叙事机制给建议，明确替代解释、不应修改的条件及可验证的小实验。
- 消息复制原始 Markdown、问题重新编辑、回答引用追问、导出本轮、历史位置重试。重试及重新生成创建新对话分支，保留原会话和后续记录；编辑和引用只填草稿，不自动发送。
- 缓存是有界、可清除的本地事实证据，不是模型训练或永久偏好学习。

## 样本边界

检查了用户授权备份内全部作品的元数据，并通过普通 Pixiv 页面查看代表性公告、说明、小说章节片段。没有声称阅读全部投稿正文；未将私人作品正文、角色或作品 ID 写入通用预设和测试。备份及密钥未进入开源产物。

## 验收证据

- TypeScript 类型检查通过。
- 全量 62 个测试文件、451 项测试通过，覆盖数据原有行为及新增正文路由、多篇读取、累计覆盖上限、会话并行、历史分支保留。
- Chrome 生产页面浏览器验收通过：配置/新建/切换、两会话并行、后台完成不抢选中项、刷新恢复、复制真实剪贴板、引用草稿、Markdown 下载、重试增加分支、390px 页面无横向溢出。
- DeepSeek 真实 Responses API：简单总览一次请求累计输入 2,178 tokens；聚合分析两次请求累计输入 6,132 tokens。
- DeepSeek 真实 API + 已从浏览器捕获的真实开头片段回放：多篇正文工具一次调用，两次模型请求，累计输入 4,793 tokens、输出 2,900 tokens；正文工具证据 3,427 字节，统计 0。浏览器标签页传输在这条测试中使用 fixture，不冒充安装态读取。上述数字是具体验收问题的观测，不是所有问题的承诺，也不是与此前 20 万输入的严格同题 A/B。
- 用户安装态反馈：两篇正文分析成功，显示约 50% 和 8.6% 覆盖率；第二篇一次瞬时错误后重试成功。证明实际正文读取链路可用；本轮最后新增的操作按钮由本地生产页面浏览器验证，仍需重新加载扩展获得更新。
- 生产构建、安装目录构建和安装产物版本校验通过，版本均为 0.5.2。

## 实际限制

原文读取依赖当前 Pixiv 登录态、已加载段落、页面结构与输入预算。长篇深入模式也可能只覆盖很小比例，回答必须披露实际覆盖率。模型仍可能产生矛盾或过度推断，提示约束不能替代核对原文。浏览器工具禁止直接自动化访问扩展页，因此安装态证据来自用户现场反馈，不绕过该限制。
