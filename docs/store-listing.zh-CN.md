# PixivPulse - 作者增长追踪

## 简短说明

记录 Pixiv 全部作品的增长快照，在本地查看趋势、转化率与可选 AI 分析。

## 详细介绍

PixivPulse 为 Pixiv 创作者记录作品数据，让每次观察都成为可以回看的增长历史。

在同一浏览器登录 Pixiv 后，扩展从作品管理页记录可用的浏览、收藏、获赞、评论等指标，在本地展示累计趋势、分段增量和转化表现。支持简体中文与英文界面，可跟随浏览器语言或手动切换。

主要功能

• 作品总览：集中查看作品集指标、近期变化、粉丝观察和排名信息（以实际可采集数据为准）。
• 作品库：按标题、ID 或系列搜索，筛选内容类型，查看单件作品的历史表现。
• 多作品比较：选择 2–5 件作品，在同一时间轴对照浏览、收藏与获赞的累计值或分段增量。
• 灵活时间范围：查看今日、近 24 小时、近 3／7／30 天、近 3 个月、全部或自定义区间。
• 持续记录：支持手动和定时同步；定时任务按北京时间固定刻度运行，手动同步不改变后续时刻表。
• 页面增长提示：在 Pixiv 作品管理页查看当天的指标变化。
• 备份与恢复：导出 JSON／CSV，导入前查看预览与校验结果；提供本地存储管理。
• 可选 AI 分析：使用你自行配置的 API 地址、模型和密钥，按需讨论作品表现。允许共享本地数据后，Agent 可查询相关统计；小说正文采样需要另行开启。

本地优先与数据边界

基础图表与统计不需要 API 密钥。作品历史和配置保存在浏览器本地。启用 AI 数据共享后，相关查询结果会发送给你配置的服务商；开启正文采样时，还可能包含所选小说的正文片段。请结合服务商政策决定是否启用。

首次同步用于建立基线。PixivPulse 无法恢复安装前的历史，也不能还原未采集期间的逐时变化。浏览器关闭或设备休眠时不采集。缺失样本与真实零增长会区别呈现，统计不等同于流量来源分析，也不保证创作增长。

PixivPulse 是独立工具，非 Pixiv 官方产品，与 Pixiv 无隶属关系。需要 Chrome 120 或更新版本及可访问的 Pixiv 登录会话。
