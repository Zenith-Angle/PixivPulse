## 真实样本与用量

用户授权的原生备份通过项目现有 SHA-256 校验及解码，覆盖插画、小说、指标历史、采集记录、粉丝及系列信息。预设强调短期观测、实际基线、类型/系列差异和小样本限制。没有将备份导入或覆盖用户数据库；个人作品及经营数据不随本记录发布。

生产 Agent 模块直连官方 DeepSeek Responses / deepseek-v4-flash，在独立会话中实测：

| 问题 | 请求数 | 实际输入 tokens | 本地记忆命中 |
| --- | ---: | ---: | ---: |
| 作品数量、总浏览、总收藏 | 1 | 2,295 | 0 |
| 新会话重复同一问题 | 1 | 2,295 | 1 |
| 全观测区间增长前三、粉丝变化、内容结构 | 2 | 6,665 | 1 |

前两项作品数量、浏览与收藏聚合结果均与本地计算核对一致。聚合分析来源无工具错误，其他复验输入为 5,974–6,665，取决于模型是否补查。不能把这些受控问题与用户先前不同问题的“20 万输入”视为严格同条件基准，也不保证所有问题都有相同用量。

预算采用保守 UTF-8 字节估算，账单 tokens 以服务商为准；服务商缓存输入已包含在总输入中，不能再次相加。

## 原文采样

读取正常 Pixiv 页面中已加载的可见文章正文，排除标题、简介、推荐区和隐藏状态。已有登录态按需打开后台页，每问最多 3 次；每次最多 900 Unicode 字符、且不超过已加载正文 20%。均衡方式将单次预算分为开头、中段、结尾三段；单点或关键词方式取该处有限片段。

真实浏览器及用户安装态均验证有限的开头、中段、结尾采样，回答标明采样覆盖与未读区间，并基于原文区分公告和虚构叙事。个人正文与具体采样记录仅保留在本地验收产物。

仅片段、位置、时间、覆盖率进入模型和缓存；页面为正常显示可能加载整篇。多页/未加载正文不在覆盖范围中。片段缓存按账号、作品、标题/发表时间及采样方式隔离，24 小时内复用，可显式刷新；远端正文修改需要重新采样后体现。独立采样开关或数据分享关闭后不提供此工具。不会绕过登录、年龄确认或访问限制。升级前旧标签页没有新脚本时，新开临时后台页，不刷新或关闭用户原有页面。

## 验收驱动的修正

- 全局生成锁和配置视图未退出：改为会话级控制器、草稿、状态。
- 粉丝摘要缺起止数值引发重复补查：补齐端点与记录数定义。
- 预算按两个最坏请求预留会在定位后过早关闭工具：改为当前估算加一次总结预算，新增三请求定位/采样回归；用户复验通过。
- 最终回答中出现 DSML 等未执行指令时明确报错，不冒充成功。
- 浏览器验收原本固定要求 S1，误报合法 S2 引用：现验证实际引用编号在来源列表存在。
